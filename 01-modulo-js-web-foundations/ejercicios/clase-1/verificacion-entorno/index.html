⚙️ Node.js y NPM

Crítico

Node.js es el motor que permite ejecutar JavaScript fuera del navegador. NPM es el gestor de paquetes.

Paso 1: Descargar e Instalar

  1. Ve a nodejs.org
  2. Descarga la versión LTS (recomendada)
  3. Ejecuta el instalador y sigue los pasos por defecto
  4. Reinicia tu computadora

Paso 2: Verificar Instalación

Abre Terminal/PowerShell y ejecuta:

node -v

Esperado: v18.x.x o superior

Luego verifica npm:

npm -v

Esperado: 9.x.x o superior

🔧 Git y GitHub

Crítico

Git es el sistema de control de versiones. Esencial para trabajar en equipo y versionar tu código.

Paso 1: Descargar e Instalar

  1. Ve a git-scm.com
  2. Descarga la versión para tu SO (Windows, Mac, Linux)
  3. Ejecuta el instalador con opciones por defecto

Paso 2: Verificar Instalación

git --version

Esperado: git version 2.x.x

Paso 3: Configurar Identidad

Ejecuta estos comandos en tu Terminal:

git config --global user.name "Tu Nombre"
git config --global user.email "tu.email@ejemplo.com"

⚠️ Reemplaza "Tu Nombre" y "tu.email@ejemplo.com" con tus datos reales

📝 Visual Studio Code

Importante

Editor de código profesional donde escribirás la mayoría de tu código.

Paso 1: Descargar e Instalar

  1. Ve a code.visualstudio.com
  2. Descarga para tu SO
  3. Ejecuta el instalador

Paso 2: Instalar Extensiones Recomendadas

  1. Abre VS Code
  2. Presiona Ctrl+Shift+X (o Cmd+Shift+X en Mac)
  3. Busca e instala:
    • Live Server - para ver cambios en tiempo real
    • Prettier - para formatear código automáticamente
    • ES7+ React/Redux/React-Native snippets - atajos útiles
    • Thunder Client - para probar APIs

Paso 3: Abre una Terminal en VS Code

Presiona Ctrl+` (backtick) y deberías ver una terminal integrada

🅰️ Angular CLI

Importante

Herramienta para crear y gestionar proyectos Angular (framework frontend del stack MEAN).

Paso 1: Instalar Angular CLI Globalmente

En tu Terminal/PowerShell, ejecuta:

npm install -g @angular/cli

⏳ Esto puede tardar 2-5 minutos. ¡Ten paciencia!

Paso 2: Verificar Instalación

ng version

Esperado: Angular CLI version 16.x.x o superior

Paso 3: Crear tu Primer Proyecto (Opcional)

Para probar que todo funciona:

ng new mi-primer-proyecto

Cuando pregunte, presiona "Y" para agregar routing

🍃 MongoDB Atlas

Recomendado

Base de datos NoSQL en la nube. Necesaria para el proyecto final del módulo.

Paso 1: Crear Cuenta en MongoDB Atlas

  1. Ve a MongoDB Atlas
  2. Haz clic en "Sign Up"
  3. Completa el formulario con tus datos (email, contraseña)
  4. Verifica tu email

Paso 2: Crear un Cluster

  1. En el dashboard, haz clic en "Build a Cluster"
  2. Selecciona el plan Free (M0)
  3. Elige tu proveedor (AWS, Google Cloud, Azure)
  4. Elige la región más cercana a ti
  5. Haz clic en "Create Cluster"
  6. Espera 5-10 minutos a que se cree

Paso 3: Crear Usuario de Base de Datos

  1. Ve a "Database Access" en el menú izquierdo
  2. Haz clic en "Add New Database User"
  3. Ingresa un nombre de usuario y contraseña
  4. Dale rol "readWriteAnyDatabase"
  5. Haz clic en "Add User"

Paso 4: Obtener Cadena de Conexión

  1. Ve a "Clusters" y haz clic en "Connect"
  2. Selecciona "Connect Your Application"
  3. Copia la cadena de conexión (connection string)
  4. Reemplaza <password> con tu contraseña

Ejemplo: mongodb+srv://usuario:contraseña@cluster.mongodb.net/basedatos

🌐 Navegador Web y DevTools

Importante

Las Developer Tools son esenciales para debuggear tu código frontend.

Navegadores Recomendados

  • Google Chrome - Excelentes DevTools
  • Firefox - DevTools poderosas
  • Microsoft Edge - Basado en Chromium

Abrir Developer Tools

  • Windows/Linux: Presiona F12 o Ctrl+Shift+I
  • Mac: Presiona Cmd+Option+I

Tabs Importantes

  • Console: Para ver mensajes de error y usar console.log()
  • Elements/Inspector: Para inspeccionar HTML y CSS
  • Network: Para ver peticiones HTTP
  • Application: Para ver localStorage y cookies
