⚙️ PROCESO

📤 SALIDA

Valor de IMC

Categoría

Fórmula Detallada:

IMC = Peso (kg) ÷ [Altura (m)]²

Ejemplo: Para 75 kg y 1.75 m

75 ÷ (1.75 × 1.75) = 75 ÷ 3.0625 = 24.49

🎯 Ejercicios para Practicar

Ejercicio 1: Crear una función de validación

Crea una función esValido(peso, altura) que:

  • Devuelva true si los datos son válidos
  • Devuelva false si son inválidos
  • Valida que peso sea > 0 y < 300
  • Valida que altura sea > 0.5 y < 2.5
function esValido(peso, altura) {
  return peso > 0 && peso < 300 && 
         altura > 0.5 && altura < 2.5;
}

Ejercicio 2: Crear una función para categorizar

Crea una función obtenerCategoria(imc) que:

  • Reciba un valor de IMC
  • Retorne la categoría correspondiente (string)
  • Usa condicionales para determinar la categoría
function obtenerCategoria(imc) {
  if (imc < 18.5) return "Bajo Peso";
  if (imc < 25) return "Peso Normal";
  if (imc < 30) return "Sobrepeso";
  return "Obesidad";
}

Ejercicio 3: Función completa de cálculo

Crea una función calcularImcCompleto(peso, altura) que:

  • Valide los datos usando la función del Ejercicio 1
  • Calcule el IMC
  • Obtenga la categoría usando la función del Ejercicio 2
  • Retorne un objeto con los resultados
function calcularImcCompleto(peso, altura) {
  if (!esValido(peso, altura)) {
    return { error: "Datos inválidos" };
  }
  
  const imc = peso / (altura * altura);
  const categoria = obtenerCategoria(imc);
  
  return {
    peso: peso,
    altura: altura,
    imc: imc.toFixed(2),
    categoria: categoria
  };
}
